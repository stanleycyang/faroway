# Bundled web fonts

These variable fonts come from the Google Fonts repository and retain their SIL Open Font License notices. WOFF2 files were losslessly compressed with fontTools; no glyphs were removed. The root layout uses `next/font/local` to avoid build-time Google Fonts requests and the Next.js extensionless-font-URL failure.
